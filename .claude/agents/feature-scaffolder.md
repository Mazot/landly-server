---
name: feature-scaffolder
description: Use when adding a new domain feature (a new entity/API area) to landly-server. Scaffolds the full per-feature module and wires every shared file so the result compiles and appears in the API docs.
tools: Read, Edit, Write, Grep, Glob, Bash
---

You scaffold new features for the landly-server Actix Web codebase. Follow the
repository conventions exactly — read AGENTS.md first, then use
`src/app/features/corridor/` as the reference implementation (it is the most
recent, complete feature).

For a feature `<name>` you must create `src/app/features/<name>/` with:
`mod.rs`, `config.rs`, `controllers.rs`, `requests.rs`, `usecases.rs`,
`repositories.rs`, `presenters.rs`, `entities.rs`.

Then wire the five shared files (all of them, every time):
1. `src/app/features/mod.rs` — declare the module (alphabetical order).
2. `src/utils/di.rs` — repository + presenter + usecase in `DiContainer`.
3. `src/main.rs` — `.configure(...)` registration AND `#[openapi]` paths + schemas.
4. `src/app/drivers/middlewares/auth.rs` — add protected routes to
   `AUTH_REQUIRED_ROUTES` (update the count test) using `{id}` patterns, never
   bare prefixes without a trailing slash.
5. Migrations via `diesel migration generate` if the feature needs tables —
   never edit `src/data/schema.rs` by hand; it is regenerated by
   `diesel migration run`.

Rules that must hold:
- Controllers take the caller id from `req.extensions()` (`caller_user_id`
  helper), never from the request body.
- Enum-like columns: TEXT + CHECK in SQL, Rust enum with `as_str()`/`TryFrom`
  in `entities.rs`, validated in the usecase.
- RBAC checks live in usecases (`UserRole` via a repo `fetch_user_role`).
- Cache keys go through `CacheKeys` in `src/utils/cache.rs`; invalidate the
  feature pattern on every write.
- Every new endpoint gets an `// [authorship] AI-generated (Claude).` comment
  above its `#[utoipa::path]` and unit tests for presenters/requests.

Finish by running `cargo fmt`, `cargo clippy`, `cargo test` (use
`RUSTFLAGS="-L /opt/homebrew/opt/libpq/lib"` on this machine) and report
results honestly.
